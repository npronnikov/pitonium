# ПИТОН V5 — переносимая версия

Приложение для изучения Python через три режима: ребёнок, подросток и взрослый. В комплекте исходный код React/TypeScript, локальный Node API и SQLite, готовая графика, 6 миров, каталог из 80 уроков, 10 полностью реализованных основных уроков в трёх вариантах и 6 самостоятельных миссий. Неопубликованные пункты каталога обозначены как готовящиеся.

## Запуск

Нужны **Node.js 24** и npm. Все версии зависимостей зафиксированы в `package-lock.json`.

```bash
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173`. Команда запускает Vite и локальный API на 8787 с согласованной проверкой Origin. База `data/piton.sqlite` создаётся и мигрируется при первом запуске. Можно открыть собственного гостя с профилями Аня / Марк / Лера, затем зарегистрировать этот же аккаунт, сохранив прогресс.

Для собранной версии:

```bash
npm run build
npm start
```

Сборка проверяет curriculum, создаёт готовый интерфейс в `dist/standalone` и скомпилированный Node entry point `dist/api/server.mjs`. `npm start` запускает обычный Node без TSX. Интерфейс и API обслуживаются одним процессом; по умолчанию адрес — `http://localhost:8787`. Установка `npm ci` для сборки включает devDependencies; уже собранный сервер работает без TSX. Операторские команды `db:*` и разработка используют исходный TypeScript через TSX, поэтому для них сохраняйте полный `npm ci` с devDependencies.

Первые команды установки требуют доступа к npm registry. Браузерная среда Python загружает закреплённую версию Pyodide с CDN; после её загрузки каждый запуск выполняется в отдельном изолированном worker. Эта поставка не заявляет полностью автономную установку без сети.

## Что работает

- Собственная учётная запись, несколько профилей, настройки режима и доступности, экспорт профиля.
- Карта шести миров, честная доступность уроков и prerequisites. Полный демонстрационный урок `for` доступен сразу из практики.
- Реальное исполнение Python, stdout, ошибки, тесты, игровые события, трасса и файлы результатов.
- XP один раз за основной урок независимо от режима; отдельное освоение навыков, повторение, серия практики и 12 наград.
- Черновики отдельно по профилю/уроку/режиму; проекты с последними десятью сохранёнными версиями и восстановлением.
- Четыре уровня подготовленных подсказок. Опциональный серверный tutor provider подключается переменными окружения; отправка кода требует явного `shareCode`.

API принимает публичное свидетельство браузерной проверки (`browser-preview`). Это учебная версия: она не заявляет защищённый серверный grader. Сервер сам проверяет владельца данных, версии и полный набор тестов и обеспечивает уникальность XP, но не исполняет отправленный Python повторно на сервере.

## Проверки и данные

```bash
npm run typecheck
npm test
npm run test:api
npm run test:runtime
npm run test:curriculum
npm run db:check
```

Тесты runtime/curriculum выполняют Python через установленный пакет Pyodide, а API-тесты используют настоящую временную SQLite. Каталог `data` содержит пользовательские данные; он не входит в исходную поставку.

```bash
npm run db:backup -- --to backups/piton-snapshot.sqlite
npm run db:restore -- --from backups/piton-snapshot.sqlite --db data/recovered.sqlite
```

Backup можно делать при работающем приложении. Перед заменой активной базы остановите API. По умолчанию recovery требует новый путь; `--force` явно разрешает замену существующего файла. Все подробности о блокировке, миграциях и границах доверия — в `docs/SECURITY.md`.

## Структура

| Путь | Содержимое |
| --- | --- |
| `src` | Интерфейс и самостоятельная точка входа |
| `packages/curriculum` | Уроки, варианты, навыки и миссии |
| `packages/runtime` | Протокол и изолированное исполнение Python |
| `packages/contracts` | Общие TypeScript и JSON-контракты |
| `packages/server`, `apps/api` | Доменный API, SQLite, локальная авторизация, CLI |
| `db/schema.ts`, `drizzle` | Drizzle schema и SQL-миграции |
| `public` | Оптимизированные ассеты приложения |
| `design` | Исходная графика, промпты, manifest, проверки и бриф |
| `docs` | Контент, API, runtime, безопасность и эксплуатация |

Основные настройки сервера: `HOST`, `PORT`, `PITON_DB_PATH`, `PITON_STATIC_DIR`, `PITON_PUBLIC_ORIGIN`, `PITON_ALLOWED_ORIGINS`, `PITON_TIME_ZONE`. Настройки опционального tutor: `TUTOR_ENDPOINT`, `TUTOR_API_KEY`, `TUTOR_MODEL`; секрет остаётся только на сервере. Без них доступны подготовленные подсказки. Пример конфигурации, если приложен, находится в `.env.example`; Node можно запускать с `--env-file=.env`, а реальные секреты не следует включать в экспорт исходников.

Переносимая поставка использует npm, Vite и локальный Node API. Вариант для приватного размещения того же проекта использует отдельный Sites/Vinext checkout с D1 и входом через ChatGPT. В этой поставке нет служебных файлов размещения, привязок аккаунта Sites, базы пользователя или установленных `node_modules`.
