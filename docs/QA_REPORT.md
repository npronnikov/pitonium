## Что именно доказано проверкой Python

Детский `for` работает для 0, 1 и 5 шагов, а шестой шаг блокируется. Тесты проверяют последовательность действий и фактическую позицию. Код с фиксированными пятью движениями не принимается для других входов. Принимается альтернативный корректный алгоритм, а не только совпадение с текстом решения.

Подростковая функция создаёт волну по входному параметру. Проверяются количество врагов, координаты и возвращаемое значение опубликованной задачи. Взрослая функция строит отчёт для пустого набора, обычных строк, нулевых значений и возвратов с отрицательной суммой.

Runtime отдельно проверяет различие между успешным исполнением и неверным значением результата, `input`, UTF-8 файлы, свежую файловую систему/глобальные переменные, тип и строку Python-ошибки, остановку бесконечного цикла, повторный запуск, смену контекста, перекрывающиеся запуски и усечение вывода. Успешный preview не подменяет набор проверок.

## Что именно доказано проверкой API

Проверены изоляция владельцев и профилей, локальный вход и регистрация с сохранением прогресса гостя, хеширование пароля/сессии, CSRF и Origin, истечение сессии, квоты, конкурирующая регистрация, собственность проектов, CAS-конфликты черновиков и проектов, история последних десяти ревизий, повторное начисление XP, идемпотентность и несовпадение evidence, подсказки и перенос освоения, выдача повторений, экспорт и удаление данных.

Проверка backup/recovery использует SQLite, а не JSON-имитацию базы. Проверены журнал миграций, целостность резервной копии, защита активной базы и отказ от неявной перезаписи. Hosted SQL-адаптер проверяется на совместимость общего обработчика; это не нагрузочный тест живого Cloudflare D1.

Все финальные PNG/WebP декодированы. Визуально просмотрены шесть миров, 24 позы героев, пять состояний помощника, игровой набор, 12 наград и эффекты. Две некорректные экспортные WebP были восстановлены до закрытия графического этапа. Master-файлы и записи промптов сохранены.

CSS проверен на существование ресурсов, валидный разбор, адаптивные правила и видимый фокус. Рассчитан контраст выбранных пар: основной текст 16,52:1, приглушённый текст 6,56:1, номера строк 5,60:1, подписи миров не ниже 5,00:1 для проверенных подложек. Масштаб текста подключён ко всем 159 объявлениям размера в стилях урока; системный reduced motion учтён и в анимации сцен.

Это проверка конкретных цветов и исходников, **не полная сертификация доступности**. Не проверены в реальном браузере переносы длинного пользовательского текста, все промежуточные размеры окна, экранный диктор, IME, мобильная клавиатура и точные hit areas.

## Оставшаяся браузерная приёмка

В сессии не было доступного разрешённого browser-control инструмента из workflow Sites. Поэтому не запускались локальный preview server или альтернативные browser automation средства. Build, React SSR и Node VM проверены; они не доказывают поведение окончательного браузерного origin/CSP.

При первом интерактивном открытии нужно пройти следующие сценарии:

1. Вход → выбор профиля → пилот `for` → три режима → запуск/проверка → рефлексия → награда → обновление страницы.
2. Проверить загрузку пяти файлов Pyodide под фактическими заголовками сайта, handshake sandbox и вывод результата.
3. Запустить бесконечный цикл, нажать остановку, затем выполнить обычный код. Во время выполнения сменить профиль и убедиться, что старый ответ не появился в новом.
4. Изменить черновики в двух режимах; переключить профиль и вернуться. Проверить конфликт сохранения в двух вкладках.
5. Сохранить проект, изменить сцену/файлы, создать версии, восстановить одну и экспортировать JSON. Проверить режим проекта при смене режима профиля.
6. Открыть помощника, запросить уровни 1–3, отдельно открыть уровень 4 и проверить согласие на передачу кода.
7. Проверить ширины 360, 768, 1024 и 1440 px, клавиатуру, Escape/Tab в редакторе, крупный текст, контраст и reduced motion.

## Известные ограничения объёма

- 70 основных уроков и 24 миссии остаются неопубликованными пунктами каталога; 240 вариантов курса не заявлены готовыми.
- Сервер не выполняет Python повторно в защищённом grader. `browser-preview` evidence можно подделать контролируя клиент; это не основа для защищённого экзамена.
- Python требует первой сетевой загрузки runtime; полного offline cache/установщика нет.
- Внешний AI-provider не был подключён или проверен реальным ключом. Подготовленные четыре уровня подсказок доступны без него.
- Нет исходной базы/кода V4 и книг. Миграция V4 и верификация книжных страниц не выполнены; ссылки имеют статус `inherited-unverified`.
- Не выполнялись нагрузочные, пенетрационные и многодневные эксплуатационные испытания или внешняя методическая приёмка всего курса.

## Воспроизведение

В переносимой поставке: `npm ci`, `npm run typecheck`, `npm test`, `npm run build`. В основном hosted checkout используйте соответствующие pnpm-команды и `build:local` для локального варианта. Узкие наборы — `test:api`, `test:runtime`, `test:curriculum`. Все тесты и исходные данные находятся в поставке; ручной запуск приложения описан в `DEPLOY.md`.
